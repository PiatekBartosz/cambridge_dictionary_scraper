# cambridge_dictionary_scraper

This project gets the definition of word in English from Cambridge Dictionary web scraping.

## Install 
```
make deploy
make install
```

## Sample Usage
```
❯ cam ephemeral

── EPHEMERAL ──

1. lasting for only a short time:
   • Fame in the world of rock and pop is largely ephemeral.

2. lasting for only a short time:
   • ephemeral fame
```
